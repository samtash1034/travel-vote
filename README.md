# 旅遊排名投票

給奕翔、玟吟、奕鈞、永裕、小汝使用的全排序投票網站。

## 啟動

需要 Node.js 18 以上，不需安裝套件：

```bash
npm start
```

開啟 <http://localhost:3000>。若要讓朋友從網路使用，將此專案部署到支援常駐 Node.js 與持久磁碟的平台，並把 `data/store.json` 放在持久儲存空間。

部署平台若掛載了持久磁碟，可用 `STORE_PATH` 指向資料檔，例如 `STORE_PATH=/data/store.json`。

## 規則

- 每人將所有候選行程排出唯一名次。
- 有 N 個候選行程時，第一名得 N 分，第二名得 N−1 分，最後一名得 1 分。
- 新增行程後，舊票需重新確認，才會納入最後統計。
- 2026/9/23 00:00（台北時間）自動鎖票並公布總分。
- 同分時依序比較第一名票數、加入候選名單的時間。

投票人直接選擇自己的名字進入。只有奕翔可以新增候選行程。
